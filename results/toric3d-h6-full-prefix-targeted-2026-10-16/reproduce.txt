files named by frozen selection.json, targeted orchestration/selection/analysis/
plot/test/checker sources, x_analysis.py and z_models.py, the transitive helpers
examples/fit_toric3d_h6_threshold.py and fit_toric3d_diagonal_feedback.py, the
shared theme/style, the unchanged independent replay verifier, the core H+6
test, project dependency declaration, and preserved document/note.tex. Every
member keeps its project-relative path. Installed environments are not included.

Restore these separately retained inputs at their original relative paths:

1. results/toric3d-h6-full-prefix-2026-10-15/ in full, including
   ARTIFACTS.sha256.json and every file listed by it. The independent production
   audit verifies the entire historical manifest, not just six raw CSVs.
   The analysis uses production-x-L11-a, production-x-L11-b,
   production-x-L11-c, production-x-L9, production-x-small and production-z,
   plus pilot metadata for stream-exclusion checks. Each production shard
   needs raw.csv, metadata.toml, checkpoint.toml and its referenced snapshot.
   The stronger production audit requires all immutable historical snapshots.

2. results/toric3d-h6-full-prefix-reanalysis-2026-10-16/x-report.json and
   z-report.json, with the exact hashes recorded in selection.json. Their
   source files are included in the source archive; these prior result files
   remain in the separately retained reanalysis bundle.

3. This targeted study's benchmark-x/ and benchmark-z/ directories, including
   raw/checkpoint/metadata/snapshot files used by the regression tests and
   excluded-stream checks. They are timing/test fixtures, never analysis data.
   For saved-data reproduction, also restore all 13 production-* directories,
   every immutable checkpoints/ snapshot, analysis/ outputs, and verification
   replay fixtures. A verification replay fixture is not a new production shard.

The source archive includes the original frozen preflight.toml and setup-freeze

ENVIRONMENT

The recorded simulation runtime is Julia 1.12.6 and conda-forge Python 3.12.13
(Clang 19.1.7), numpy 2.5.1, scipy 1.18.0, ldpc 2.4.1 and pymatching 2.4.0.
Plotting used matplotlib 3.11.1. Python must be at least 3.11 for tomllib.
The recorded Project.toml and Manifest.toml provide Julia dependencies; prepare
that environment before running these commands. The unchanged resume/replay
checks also compare the absolute Python executable path, runtime version string,
package versions and environment. Exact checkpoint replay on another machine
requires recreating the recorded path/environment; relocating the executable
without matching those guards is not an exact replay. Do not edit saved runtime
metadata or relax the guards to conceal a mismatch.

SOURCE PLAN AND EXTRACTION CHECK (NO SIMULATION, NO ARCHIVE CREATION)

"$H6_PY" -B "$H6_STUDY/archive_sources.py" --smoke --plan-file /tmp/h6-targeted-source-plan.json

Planning first verifies the prior report and manifest bindings in the restored
workspace. The smoke check then copies only the listed sources to a temporary
empty tree, verifies all hashes, and imports analysis, plotting, both inherited
analysis helpers, both transitive likelihood helpers, the theme, tests and checkers
using isolated Python. That isolated stage checks frozen fit/profile schedules,
basic interval arithmetic and no-grid styling without loading prior data,
optimizing, simulating or writing PDFs. A provisional plan is not a final source
freeze: regenerate it after the scripts are finalized. The --verify-archive mode
uses the archive's embedded manifest and runs this same isolated check without
requiring the separate data bundles to be installed.

SAVED-DATA REANALYSIS AND FIGURES

The following commands use the existing samples, retaining fresh data as primary
and old-plus-new same-cell pooling as secondary. They write to a separate output
directory to preserve the retained final report. A reanalysis is not a new
independent experiment. No post-outcome window/model selection is performed.

"$H6_PY" -B "$H6_STUDY/analyze.py" --validate-only --output-dir /tmp/h6-targeted-reanalysis
"$H6_PY" -B "$H6_STUDY/analyze.py" --profiles-grid 301 --output-dir /tmp/h6-targeted-reanalysis
"$H6_PY" -B "$H6_STUDY/verification/check_numerics.py" --analysis /tmp/h6-targeted-reanalysis --output /tmp/h6-targeted-numerical-audit.json
"$H6_PY" -B "$H6_STUDY/plot_targeted.py" --report /tmp/h6-targeted-reanalysis/report.json --output /tmp/h6-targeted-reanalysis/figures

The independent numerical checker reconstructs saved likelihoods, residuals,
profile statistics, crossing bands and bootstrap count arrays without importing
analysis/model helpers or refitting. Completion can be complete_with_numerical_failures;
failed/missing calculations and numerical flags must remain in the report and
figures. A passed arithmetic audit does not establish an asymptotic threshold.

Five PDFs are written: x-data.pdf, z-data.pdf, x-crossing.pdf,
z-size-sensitivity.pdf, z-profile.pdf. The data figures contain fresh measured
points, pointwise 95% Wilson intervals and straight joins only. Their state-failure
metric is the union of the two logical parity failures. The diagnostic PDFs show
saved analysis values, all planned leading/1-L subset comparisons, and failures.
Render the final PDFs with Poppler and inspect every page before delivery; the
source-only smoke check is not a substitute for final PDF visual verification.

CHECKPOINT RESUME VERSUS A CLEAN FROM-SCRATCH RERUN

Never run two copies of the same worker. The two distinct workers may run
concurrently; each owns the jobs assigned to it in jobs.toml.

julia --compiled-modules=existing --project=. --startup-file=no "$H6_STUDY/run_worker.jl" 1
julia --compiled-modules=existing --project=. --startup-file=no "$H6_STUDY/run_worker.jl" 2

In a tree containing checkpoints, these commands automatically pass --resume.
A completed shard is checked, its mirrors rebuilt, and returned without drawing
or decoding new records; worker log entries may be appended. An incomplete shard
resumes its exact stream to the frozen shot count. This is continuation, not a
fresh run and not a new statistically independent replicate. Use a copied tree
if preserving every original artifact byte and log is required.

For a clean from-scratch reproduction, extract the source archive into a separate
empty project-root directory. Restore the old-study inputs, prior reanalysis
reports, targeted benchmark fixtures and frozen preflight, but do NOT restore
any targeted production-* directory or old targeted analysis/figures outputs.
Run the read-only design audit, then the two worker commands above in that new
tree. Their output paths are derived from run_worker.jl's location, so they stay
inside the new tree. Do not delete the original production directories to make
room. The same frozen seeds regenerate the same logical fault streams; rerun
records must never be pooled as new independent samples. Counts should match;
wall-clock timings, timestamps, logs and resulting checkpoint hashes need not.

This step was prepared while production was running. It must not be run until
the report and all source changes are finalized and the final production and
numerical audits have passed. Save those final audit outputs at the canonical
paths below. A numerical audit with retained failures may pass when it verifies
that those failures are honestly classified; do not relabel the analysis complete.

"$H6_PY" -B "$H6_STUDY/verification/check_production.py" --output "$H6_STUDY/verification/production-audit.json"
"$H6_PY" -B "$H6_STUDY/verification/check_numerics.py" --output "$H6_STUDY/verification/numerical-audit.json"

The creator refuses incomplete/missing reports, failed audits, changed audited
raw/checkpoint/metadata files, stale numerical report/input/checker bindings,
changed frozen sources/setup files, changed imported numerical helpers, and an
existing archive or receipt path. The full immutable-snapshot validation remains
the responsibility of the immediately preceding independent production audit.
It writes a source-only tar.gz with SOURCE_MANIFEST.json,
then extracts it to a fresh temporary tree, verifies every member hash and runs
the isolated import smoke check before promoting the archive. The companion
source.tar.gz.receipt.json records the archive hash, final report hash and smoke
result. Production data/checkpoints and final reports/PDFs require their separate
retained data bundle and artifact manifest; this archive does not replace them.
