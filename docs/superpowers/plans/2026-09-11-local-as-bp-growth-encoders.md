# Local As/Bp Growth Encoders Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the RREF/route-SWAP schedules with the literal local As and Bp plaquette-growth circuits, while retaining one selectable rotated-planar logical qubit and the existing noise/decoder APIs.

**Architecture:** The Typ diagrams are a direct `:x_ew` template, after mapping `siteXY` to row-major `(row=d-Y+1, column=X)`; `:x_ns` is generated by a 90-degree rotation of the resulting operations. A canonical local-growth scheduler owns source checks, physically fresh representatives, directed nearest-neighbour trees, and sequential plaquette blocks. It is the only schedule consumed by Yao, Pauli-frame noise, and the comparison runner.

**Tech Stack:** Julia 1.10+, TopoNoise.jl, Yao.jl, PythonCall/PyMatching, Random, LinearAlgebra, Julia Test.

**Spec:** `docs/superpowers/specs/2026-09-11-local-as-bp-growth-encoder-design.md`

> **Validated implementation amendment:** d=3 retains the literal Typ time
> order. For d>=5 the fresh-representative condition requires deterministic
> reverse shelling rather than sorting every executed block by diagonal. The
> final scheduler peels eligible checks by unique-qubit count and check index,
> reverses that order, and is tableau-tested at d=3, 5, and 7.

## Global Constraints

- Preserve CSS meanings exactly: `A_s = product(Z)` and `B_p = product(X)`.
- Keep `RotatedPlanarCode` as an odd square one-logical-qubit patch at `d >= 3`, with both `:x_ew` and `:x_ns` boundary orientations.
- Treat the d=3 operation lists in `document/image/2DcircuitAs.typ` and `document/image/2DcircuitBp.typ` as the executable golden reference for local direction and representative choice.
- `:x_ew` is the direct Typ orientation; `:x_ns` is exactly its 90-degree clockwise rotation.
- Each stored plaquette block must execute completely before the next block. Its CNOTs must be physical nearest-neighbour edges; never insert routing SWAP triples or use a row-reduced support.
- A block's representative must not have occurred in an earlier plaquette block of the same construction. It begins in `|0>` before its block H; Bp's rooted X branch and As's incoming Z branch must reproduce the stated d=3 directions.
- Keep `logical_state in (:zero, :one, :plus, :minus)` and make As/Bp a construction selector only: both must encode the same requested logical state.
- Leave final perfect syndrome extraction, binary Pauli-frame propagation, PyMatching decoder sectors, scan/comparison APIs, and plots generic over the canonical schedule.
- Do not modify user document artefacts, Typ sources, `.CondaPkg/`, `results/`, or unrelated current changes in `scaling.jl` / `test/rotated_planar/scaling.jl`.
